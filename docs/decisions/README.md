# Decision records

One file per architectural decision: `NNNN-short-title.md`.

    # NNNN - Title
    Date | Status: proposed | accepted | superseded by NNNN
    ## Context      What forced the decision. Cite the spec section.
    ## Decision     What was chosen.
    ## Consequences What this makes easy, what it makes hard, what it forecloses.

Record a decision whenever you resolve a spec ambiguity, choose between viable designs,
or deviate from CLAUDE.md. `PROGRESS.md` links to these; it does not duplicate them.
